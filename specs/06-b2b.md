# Spec 06 — B2B quotes

## Acceptance criteria
1. Buyer accounts sign up through Cognito (group `buyer`) and must be approved by an admin before they can request quotes.
2. A quote request lists `{sku, qty}` lines. The system prices each line with tier pricing and states availability (in stock qty, or made-to-order lead time).
3. Quotes start `requested`. Admin can approve (optionally editing unit prices, never below floor) or reject.
4. Approving a quote reserves stock by writing ledger `SALE` events with idempotency key `quote:<id>:<line>`; if stock is short, approval fails and nothing is written.
5. Buyers see only their own quotes.
6. No supplier identity in any buyer response (spec 07).
